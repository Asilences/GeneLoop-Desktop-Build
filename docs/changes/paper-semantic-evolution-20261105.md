## 三、首轮Gate 1—5

### G1 自主调查

从已恢复清单接入真实来源、任务和运行身份。先用成功复用、质量偏差及未采用三类记录检查投影，再覆盖全部30次，保留重复与反例。

宿主按原事件生成可展开skeleton，原能力内部默认折叠，事实与解释分开。以中性小概览启动，允许Evolution自行检索。S4误报、QLoRA分组线索作为可查询事实。

验收是模型自主选择问题、按需核对原件和对照，搜索路径与未读范围可重现。当前先做身份、证据和读取的离线核对，真实自主调查另计模型运行。

### G2 自主决定

复用原note、candidate和finish保存问题、支持、反例、假设、范围、后继行为变化及否定条件。区分无修改决定与证据不足。

定位现有至少两来源限制的具体位置，使单例局部候选能表达。跨来源与准入范围的规则保持一致；旧路径行为通过回归核对。

验收是一个可检验的真实候选、合理no_change或明确inconclusive。模型未提出候选时按决定性质报告，不强行编写成功产物。

### G3 真实接收

本轮优先已有能力或条件策略接收器，其余类型附具体pending原因。产物记录精确版本及准入范围；host_selected和model_selected分别保留。首轮允许宿主显式选择检验接收，通用自动选择可后补。

验收是候选实际进入原构造或独立策略评价，并具备明确后继接收位置。模型产物文件本身只表示候选存在。

### G4 独立验收与实际采用

发现材料可查询，开发验证可用于修复和筛选并记录暴露；封存评价在候选、输入和标准冻结后运行，未公开答案及其派生物隔离于调查工具。

本批优先原确定性oracle，LLM judge仅用于另有需要的解释性质量。五篇本轮评价报告历史回放，新的未见泛化另设资料及覆盖条件。

能力以版本化调用回执检查，任务策略以实际行动检查，构造策略以Builder后继行为检查，边界产物以新版本后继执行/构造检查。选择声明与读取收据单独保留。

分别记录独立验收、采用和后继效果。允许质量提高而费用增加的mixed、质量相同而费用增加的negative，以及结果无差异的neutral。缺少可比条件时为inconclusive。

### G5 反馈回流

将实际动作、质量、成本、失败及选择方式接回原经历体系，下一轮通过相同工具可查询。评价反馈被用于改进后，更新暴露角色。

no_change可以回流调查决定，G3/G4标不适用；候选已验收但无后继任务时，采用保持待发生。机制故障保留断点，不能转换为no_change。

验收是下一轮能读取到真实新经历或调查决定。首轮无需声称多代收益，完整Builder自应用和连续递归另分阶段。

## 四、费用、终止和运行快照

费用/请求上限使用已有用户授权的null及累计账本。0禁止新增付费，缺失字段不得静默解析为不限。单次启动前明确实际模型、推理模式、输出容量及所有有效配置。

调查步骤上限、截止时间、候选/修复次数、可读范围及单次读取大小必须为已确定的有限边界；具体值由实际宿主配置给定，本轮未设置运行数值。每次查询、展开、笔记及提交按既定口径计入调查步骤。

达到期限、步骤或候选流程终点、模型finish、取消和重复失败边界时，保存当前决定或缺口及断点。恢复同一调查沿原账本与已用逻辑额度续接。

实际快照包含代码SHA与dirty差异、输入/题面/工具及顺序、能力库、策略、评价器、数据角色及资源政策。任务开始冻结能力和策略版本，新增产物默认在下一任务生效。

## 五、抽象贡献的评价顺序

先记录可见、读取、实际调用、构造引用及结果。因果贡献需要条件可比的评价；删除依赖后某程序无法运行只支持实现依赖。

若研究后继构造成本，保留直接实现或重新规划能力，固定任务目标、质量、材料暴露、模型和工具。按实际假设选择有C、描述条件或原基础材料等对照；长期因果Creation Value可pending。

任务执行、调查、候选构造、检索、认证、评价、修复、失败和人工修订分别计量。旧Baseline可用于历史定位，当前条件变化逐项列明；新增净收益以可比证据为准，不默认重新付费采集旧Baseline。

## 六、依赖与可保留pending的项目

```text
当前已恢复的30次原记录
    → 身份/证据强度/skeleton/质量动作及费用关联
    → G1 自主调查 → G2 自主决定
        ├→ no_change / inconclusive → G5 决定回流
        └→ proposal → G3 原接收器 → G4 验收与行为/效果 → G5 新经历
```

概念核查完成后，先检查12项最小矩阵，再启动真实G1/G2。G3—G5按实际候选推进；接收适配审计可与输入投影准备独立进行。当前未派发子Agent或源码任务。

下列事项保留后续研究位置：多候选最优匹配、完整构造策略自主学习、三代以上增长、跨领域推广、长期因果Creation Value、最优演化频率与再投资比例，以及完整重复高层图编译缺口。
