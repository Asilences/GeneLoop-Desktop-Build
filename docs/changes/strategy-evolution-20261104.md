# 条件化策略演化实施计划

依据网页会话 `6aeaca67-4fa8-83ed-a4dc-9401a02e1716` 最后一轮确认，Strategy 由开放决策 Policy、已认证 Motif 引用和真实 Evidence 共同组成。稳定执行继续走原 Capability Runtime 与 Motif 学习流程。

核心目标是让真实反馈改变后继任务或能力构造中的决策方式，包括目标与任务分解、已有能力选择、组合顺序、验证范围及恢复方式。策略中的稳定执行片段再进入原学习链，成为下一轮可调用的操作。问询仅是可观察行为的一个例子，场景选择与验收不限定于该行为。

## 基线与审计

- 远程 main 为 `b8e042965487a80305c851324f1e911a57ccfa8a`，已含 PR132。PR133 的 `04d6d7b5` 提供本轮依赖的 Evolution Agent，已在隔离研究分支整合。

## 树状依赖与文件分工

```text
T0 规格与最小审计（主 Agent）
├── T1 策略定义、版本引用、独立准入与撤回（协议子 Agent）
│   └── T3 Builder 有界继承与使用记录（接线子 Agent，依赖 T1）
├── T2 真实任务/构造的语义证据适配（证据子 Agent）
└── T4 Evolution 紧凑视图与策略候选处理（主 Agent，依赖 T1/T2）
    └── T5 端到端机制验证、兼容库、回归及交接（主 Agent，依赖 T3/T4）
```

T1 使用既有摘要、FileRef、Feedback 与认证能力引用，定义策略候选和宿主独立验收。T2 引用真实任务事件、构造 journal 和宿主脱敏投影，区分原始事实与解释。T3 让经宿主准入的有限策略实际进入原 Builder Prompt，记录所选版本，编译及 Runtime 使用另行核对。T4 沿原模型调用和账本处理策略候选，宿主冻结验证要求。T5 验证成功、失败、no_change、失效和关闭路径。

## 验收

- 候选具备适用条件、决策文本、认证依赖、来源证据及版本，候选无法授予自身权限或通过认证。
- 真实证据可重建，跨任务独立性及成本未知保留。默认紧凑上下文有总量上限，语义内容须为宿主批准的脱敏文本。
- 后继 Builder 的实际 Prompt 可追溯到策略版本，已学执行片段仍由原 Runtime 执行并进入原 learner。
- 原任务问讯记录可进入证据；需要用户回答时沿原问讯工具生命周期。
- 本地机制诊断与服务器真实模型验收分别记录。真实自主效果无结果时保留 pending。
- 新机制默认研究关闭，原版本保留。公共运行时与接口变化执行 Python/Node、smoke、Motif、RAE 和 RSI 回归。
