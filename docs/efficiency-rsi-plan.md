## 目标与首个里程碑

通过可执行抽象降低执行和后续能力构造的计算成本，并把收益回归到 Agent 能力：同样资源下完成更多合格任务，或自发构造原先在该资源条件下未能构造的能力。

必须同时检验两种收益：双方成功时的成本改善，以及基线失败而新方法成功的能力可达性改善。不能假设 Agent 总能直接写出 C/D；抽象 A/B 可能正是构造 C/D 的必要支撑。此处“此前做不到”指冻结模型、工具、任务和资源条件下未观察到成功，不声称绝对不可解。

首个里程碑：Agent 从真实轨迹学到的 A/B 参与新 C 的自主构造；独立验证后，C 进入下一轮并参与 D 的构造。新旧路径真实执行，记录所有尝试、质量、依赖与费用。没有发生组合或没有收益也如实交付，不为制造谱系硬编码 A/B→C→D。

立项依据是“效率反馈如何支持能力获得”这一具体、有研究价值的问题；递归组合、双价值名称或库增长本身不作为首次创新主张。多轮可停滞、失败或负迁移，保留完整谱系。持续收益和论文贡献强度仍待实验。

## 复用已有实现及必须补齐的接缝

- 已有 [RSI 共同协议](rsi-protocol-v1.md) 和 `rsi_quality.py/.ts` 可复用：精确字节摘要、可信宿主准入、真实派发回执、任务/产物/rubric 绑定、独立验证与原子发布。
- 当前更新组件只覆盖 `motif/matcher/reuse_form`，没有 Capability 组合变更类型。T6 必须扩展受检协议和兼容测试，不能把新组合伪装为 `reuse_form_revision` 或允许任意未知字段。
- `source_program_runtime.ts` 当前校验并实例化源码，实际执行仍属于场景后端。新 Runtime 通过既有后端执行，不能因返回源码成功就记录执行成功。
- 现有 [优化协议](rsi-optimization-v1.md) 的配对评价会拒绝 `baseline_quality_failed`；视频 `evaluate_form` 不要求基线全成功，但仍以默认 20% 前向降费为主要门槛。二者都不能直接代替新能力可达性评价。采用独立版本化研究目标和可信 validator，保留旧门槛与旧结果。
- 新组合必须单独认证。旧叶能力的来源等价或局部正确性证书不能累加成新组合的独立质量证明。
- 旧学习器继续做其原有参数化/描述学习；新 Builder 消费既有能力，不重写所有旧学习算法。

## 最小契约与迁移约束

T1/T2 首先冻结五种概念：固定版本的能力引用、能力修订、任务依赖快照、实际调用回执、双价值观测。价值观测与能力身份分离；谱系父边、生成时实际调用、执行时实际调用和最终产物采用分别记录。

生命周期、认证状态、迁移状态分别表示，不由一个 `active` 字段授予权限。Build-only 指不直接向普通任务选择器暴露；若已认证组合依赖该能力，执行仍需解析固定版本并检查既有权限。归档退出活跃选择，不删除被依赖的版本。

必须覆盖以下实际接缝风险：

1. 任务开始固定整个依赖闭包；不能仅在 effective.json 记摘要，之后仍按路径读取另一份自洽新库。
2. 旧 Remotion runner 的同题容器清理标签可能跨臂冲突。首轮串行，按 experiment/run/arm/nonce 实现归属保护后才能并发。
3. 取消只阻止后续动作，不假称撤销已完成副作用；状态不明的外部写操作不得自动换旧路径重做。初版限只读及隔离产物写入。
4. 保留原生 Agent 循环、网关、计费和沙箱，不造第二套部署器。首轮无需修改网页双栏组件。
5. 新层先表达固定版本调用和类型化数据流，保留叶程序已有分支/循环；未支持控制流明确拒绝/交接，不能悄悄展平或开放任意代码求值。

## 实验判据

第一组对照区分基础工具、仅执行复用、执行加构造复用；允许基线正常写代码。另设可读取旧源码的普通复用对照，避免把提供信息本身归因于结构化抽象。库按臂/重复运行独立维护，不能向对照泄漏候选臂学出的 C/D。

| 基线结果 | 候选结果 | 记录与解释 |
|---|---|---|
| 成功 | 成功 | 同质量成本差、执行与构造开销；这是条件比较，不代替全样本结论 |
| 失败/预算耗尽 | 成功 | 该资源条件下能力可达性改善；基线实际支出保留，成功获取成本未观测/null，不能记成无穷或虚构省费 |
| 成功 | 失败 | 质量/可达性退化，计入全部失败与恢复成本 |
| 失败 | 失败 | 无解/资源不足/基础设施错误分列；保留花费，不移出分母 |

最终报告同预算任务成功率、独立通过的能力数、成本—成功率曲线、达到固定合格目标的累计成本及删失；双方成功的成本比较作为补充。程序层数和后代数量不是能力强度的替代指标。

构造、修复和在线晋级反馈可用于学习；最终 heldout 不参与选择。生成、失败、重试、认证、学习、检索绑定、管理和恢复全部计量。所有物理请求按账本身份去重；实验实际总支出、各臂公平分摊预算和生产摊销外推分别报告。未知费用保持 null，代理估费不是供应商账单。

预算再投资在 T7 单独对照。对照也可普通自适应分配预算，不能人为禁止它花剩余资源。节余再投入后，总支出可能相同，此时报告同预算能力/合格任务产出，不能把同一笔资源同时当净省费和新增投入。
