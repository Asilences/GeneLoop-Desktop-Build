# ADR：日常 File 任务接入决策程序学习

状态：已接受；2026-11-11。依据用户“功能完善第一优先级”的授权，本轮只在本地实施，不推送、不切换正式服务。

## 背景与选择

原日常任务已有结构 Motif/脚本后台；新决策程序仍由私有实验驱动触发，未从日常入口加载。选择复用原任务封存、账户 pool、编译器、独立审阅器与长期经验库，在原 `rsi.patch.yml` 内冻结决策插件；原任务恢复自动继续使用同一 patch。

考虑过继续仅提供实验入口，无法满足日常自主学习；也考虑重写统一规划器，会重复现有 Harness。本轮均不采用。

## 接线

`continuous_rsi.enroll` 在真实 management_v3 的 learn 入口加载已认证程序并透明记录剩余模型决定。任务封存后，原 `launch_worker` 同时启动原后台及 `rsi-worker --programs`；两个后台使用不同写锁、同一个原账户账本，避免旧结构认证拖住新程序学习。

新后台复用实际普通任务轨迹自动选点、模型生成/修订、纯程序编译与守卫诊断。模型见过的全部任务均计入训练暴露集合。候选等待后续普通任务的新资料，在授权目录内创建认证副本，使用原权限、原费用与修复策略实际替换工具决定，并独立审核局部效果和整任务。至少两份新材料通过后，由现有发布器入原长期库，后续任务自动加载。

## 后果与边界

- 运行中任务不热换库；候选不直接接管未认证的用户任务。
- 旧原生库、旧程序、失败、认证副本和费用保留；暂停程序不能成为复用原型。
- 没有新独立资料时显示等待，不能把同一老师的续写或训练资料当作新认证。
- 无配置的语义服务或有限且未能核价的费用授权保持 capture-only，不扩大权限或配额。
- 不以已证明净降本作为学习前提。本轮不跑新九对基准，也不把试验端点调用当作生产前端已更新。
- 学习范围仍受原解释器和单工具决定捕获范围约束；完整源码及跨工具图仍使用已有脚本/结构学习路径。

## 本轮验证补记

两份后续新材料认证实际替换、局部审核及整任务双评通过，后继普通入口无候选override自动复用。成功程序迁移v9同一执行核心，不把它称为全新结构发现。另有新工具根和守卫失败候选保留。只修改后台学习代码的兼容包装须核对在线hook AST/导入/常量和其它全部依赖不变，保留原独立证书、明确不是新质量认证。完整结果见本地实验记录。
