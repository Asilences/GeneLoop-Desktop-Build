## 本轮唯一主问题

已有高层能力 C，能否帮助同一个冻结模型，在相同预算下，以更低的能力获取成本或更可靠的方式构造具有新增跨文件、跨版本关系的 D？任务成功与是否选择 C 分开判断。

已有书目计数闭环与视频复用收益保留。本轮改变复杂度增长方式：增加真实依赖、全局一致性或状态关系，不以重复调用数、嵌套深度、目录可见性作为能力边界扩展证据。

## 能力阶梯与今晚范围

| 层级 | 任务目标 | 必须增加的关系 |
| --- | --- | --- |
| L0 | 读取和解析 BibTeX、LaTeX 引用、文件依赖与版本差异 | 正常原生工具、代码和已有可认证原语 |
| L1 / C | 引用一致性审查：关联正文引用和书目，识别缺失引用、重复键、未引用条目并返回来源证据 | 多种输入共同决定结果、文件覆盖与版本绑定 |
| L2 / D | 跨版本一致性：比较两个文档版本，定位新增/已解决问题、受影响文件及全局报告 | C 的结果参与新增关联/差异决策；不能只是两次输出拼接 |
| L3 / E | 多文件、多版本增量检查与失效传播 | 本轮暂缓，不以提前实现框架替代 C→D |

C、D 必须是模型实际生成、独立验证并保存的 Capability；普通任务输出或人工编写的最终算法不能冒充能力构造。最终验收检查机器可核验的字面引用一致性，不扩大为文献真实性或全文科研判断。

## 冻结与公平对照

1. 尽量采用至少两个独立文档项目；区分真实论文与公开样例，标记来源、版本、训练/认证/留出用途，避免同一书目分区冒充独立项目。所有材料选择在观察构造结果前固定。
2. 预先固定 C/D 的行为、D 新增的跨组件约束、输入、模型、工具顺序、独立质量规则、评测器摘要、费用和超时策略。失败后不降低判据、不删除失败任务、不按 Agent 当前能力重写题目。
3. Direct：保留正常写代码与基础工具的能力。Flat / Without C：可用全部相同底层原语，但不提供高层 C 的接口。Hierarchical / With C：相同底层条件加 C。今晚优先完成后两组的 C 移除对照，Direct 能在相同原生入口运行时一并采集。
4. D 的正式运行允许自主选择，不能提示“必须调用 C 才算成功”。强制依赖只可单列为机制诊断。隐藏 C 时同时移除其高层接口/可见定义，保留形成 C 的底层原语和普通代码能力。
5. 各 D 组使用同一有限研究预算，运行器在真实 booking 边界执行；不能仅靠事后测量器判断预算。该有限实验配置不改写平台 null 额度、旧账本或正式服务策略。C 的获取成本另列，共享/研究开销预登记，条件 D 成本差不等于全系统已回本。
6. 供应商账单、人工与机器成本未知则 null。正常、失败、修复、认证、验证、恢复及未结算请求完整保留；先冻结 owner、再发送请求，使用 PR #122 的独立归属 journal 和原累计账本，不从成功结果反造库存。

## 验收证据

- C 来源于真实轨迹或模型构造，并通过冻结的独立认证。
- D 是新增可执行能力，满足新增跨文件/版本约束；不是纯包装或报告文字。
- 若 D 选择 C，记录精确版本依赖以及实际原生父子调用回执；不只看文本声称或目录可见。
- 完成隐藏 C、保留底层能力和普通编码的对照；未完成组继续占分母。
- 收齐每组全部尝试、质量、请求、缓存/未命中输入与输出 token、费用、耗时和恢复证据。
- 旧 Runtime、库、权限、原始数据和累计账本未受破坏；新实验不接管产品聊天，不发布生产。

## 定位失败时的决策

| 观察 | 下一步 |
| --- | --- |
| C 不能可靠生成/执行 | 定位学习、契约、认证或执行的最小失败；不越过 C 宣称 D 成立 |
| C 已认证但 D 不选择 | 核对能力可见性、语义描述和选择事实；保留未选择结果，不强行改提示 |
| 选择 C 但现有 IR 无法表达新增关系 | 保存具体反例；必要时增加最小、安全、有界的控制或数据处理原语，再另开条件版本 |
| D 成功但没有省费/没有扩大能力范围 | 报告实际构造与验证开销、抽象粒度，不追小样本正收益 |
| D 只在旧输入上通过 | 标记特化/覆盖不足；保留独立输入反例，不把修过的留出集当初次测试 |

候选、IR 或 Runtime 修复都使用新的条件 ID 与固定代码目录；已被证据引用的源码不原地覆盖。冻结后评测器不随候选变化。必要的实现修复可推进，但要保留原始失败和改动前后的区别。

## 七小时顺序与暂缓项

约 40 分钟核对版本/隔离与必要回归；约 55 分钟冻结任务和判据；约 85 分钟学习与认证 C；约 80 分钟自主构造 D；约 75 分钟隐藏 C 对照；约 50 分钟质量/费用/谱系复核；约 35 分钟整理并提交独立研究 PR。以实际阻塞调整，不把时间表当完成记录。

暂缓 Reuse-Aware Execution、自动再投资、全局工具淘汰、任意 MCP、Meta-Agent、SWE-bench/Terminal-Bench 和大规模随机任务。通用语义契约只在实际任务需要时接入少量可检查性质，不实现通用证明系统。F8 深依赖图问题仅在真实递归/规模测试需要时做迭代遍历修复，不挤占本轮主要实验。
