# 统一邀请码（2026-11-03）

## 范围与原因
原邀请码永久但单次，注册后 usedBy 被消耗，无法让所有新用户共用。新增显式共享码，长期、无限次重复注册；只有一个活跃共享码，明确换码才撤销旧码。每个新用户仍获得独立 member 身份、密码与资料空间。旧单次码保留。

## 实现
`harless_gateway.mjs` 增加共享码管理与注册二次校验，服务器只存哈希，成功使用计数与换码历史保留；owner API 要求当前密码，CLI沿既有 loopback adminToken 管理。两处账户界面优先展示统一邀请码，旧批量单次入口默认折叠；明文仅生成时显示，不存浏览器localStorage。

Paper45/PPT42 是 gateway 源码锁的兼容导出，原IR、manifest、task、tool schemas、来源证据保持字节一致，旧库保留。没有重新训练、修改原算法或增加模型调用。基于GitHub main 2f29d34；本次同时保留该版本已合并的413响应修复与研究代码，默认实验开关不变。

## 验证与发布
服务器网关28项测试、UI17项测试、兼容与产品库46项测试通过，覆盖并发不同用户、用户名竞态、重启持久化、scrypt期间换码、原单次码、角色注入拒绝、owner权限、复制失败回退及明确换码交互。完整回归与正式注册结果见下文。

本轮没有模型调用。共享码无限使用不等于取消独立的注册频率防滥用校验。
