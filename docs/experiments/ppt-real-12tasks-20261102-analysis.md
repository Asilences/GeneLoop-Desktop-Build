## 4 / 如何解读降费

1. **有批次总量下降，尚无稳定性证明。** 7/12题更便宜，逐题费用变化的中位数仅下降2.07%。T04与T08贡献的绝对节省超过整批净节省；事后敏感性分析剔除二者，余10题费用上升2.23%。这不是修改主指标或剔除负例，只是说明总量易被长链路波动支配。
2. **504次净请求差不能全部归因Motif。** 执行审计只直接证明12次认证旁路；其余差额受到模型内容规划、工具选择、渲染修复与重做次数等影响。缺少同一路径的逐决策消融，无法给出纯机制因果费用。
3. **输入token下降不等于相同比例省钱。** 输入总量下降23.40%，但未命中输入反而增加4.99%；两组输入绝大多数来自缓存。必须按命中/未命中/输出分别计费，而非仅用总token比率。
4. **续改的收益要单独看。** T11两轮合计降费3.89%，但只看第二轮修订，B27请求/$0.05798512，O33请求/$0.07215763，优化修订反而更贵约24.44%。T12第二轮B93/$0.12003101、O23/$0.03704977更便宜；随后导出原稿核实，O最终答复明确因未继承旧PPTX而无法完成、不交付文件，工作区及第二轮登记交付均无PPTX。它是语义任务失败，不是成功降费，即使Runtime记录为completed也不能算任务完成。
