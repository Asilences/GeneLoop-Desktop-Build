## 复现入口

`npm run rsi:improve -- --plan <私有宿主计划>`预览，服务器使用同入口追加`--call-model`执行。计划用原字节`scene_adapter`引用`scenarios/ppt_master/capability_adapter.py`并固定`scene_dependencies`。PPT独立发布材料格式由该适配器验证，包含owner、libraries以及validation/followup的独立输入和SVG/PNG参考证据。

宿主`publish_capability.mjs`复用`completeCapabilityCycle`，叶执行交给`artifact_capability_runtime.ts`及原Artifact沙箱，模型不能改验证标准、授权或认证结果。已发布根在未来任务冻结加载，原页面工具按目录中的Capability ID执行；渲染仍沿`finalize_ppt`。
