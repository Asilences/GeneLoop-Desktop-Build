## 学习与独立认证

四项普通训练分别使用公开的 RoBERTa（13 页，1907.11692）、BART（10 页，1910.13461）、Transformer-XL（20 页，1901.02860）、Longformer（17 页，2004.05150）。隔离学习配置实际从空库启动；原协议预期沿用旧种子的描述已在私有实际配置记录中更正。四项均交付合格，137 次模型请求，峰价用量估费 USD 0.09531068。

前两项只有一条不受 todo 插入打断的完整循环见证，保留短片段和拒绝记录，追加两项独立普通探索后由既有编译器产出候选，没有放宽门槛。每项候选再以 ELECTRA（18 页，2003.10555）、BERT（16 页，1810.04805）、XLNet（18 页，1906.08237）的新正文执行一次独立普通认证、两次候选实际执行。认证材料与全文覆盖／原件不变标准在调用前冻结，未使用最终评测集；不是只改 PDF 元数据的副本认证。

六次独立认证均通过、零修复、零回退、用量完整。两次普通认证 55 请求／USD 0.03806812，四次候选执行 43 请求／USD 0.07015175；本轮探索与认证总计 USD **0.20353055**。材料编排使用现有 worker，本 PR 没有升级日常自动认证材料生成器。

## 有效配置、失败与完整支出

执行模型 `deepseek-flash`，`reasoning_effort=off`，评审模型 `deepseek-v4-pro`。本地 Mac 隔离副本；每会话预算 USD 1，输出 16,384 Token，最多两次原验收修复。原生步骤／请求上限使用受支持的 `null`，实验平台代理另设每任务 256 请求；这是有限诊断配置，不改变正式平台 policy。原系列 USD 1000、学习 USD 25 及历史累计沿用；本轮封套 USD 50，其中学习／认证最多 USD 5，旧未知 USD 10 预留不清零。

## 分发、兼容与恢复边界

新载荷为 `sss-operation-flow-v3`，认证为 `sss-operation-certification-v3`，每次接管最多 **64 步**。30 页任务两轮完成整条循环；67／75 页的四个 L 会话触及边界后回退普通 Harness，最终仍合格。局部跳过不记作整条循环成功；未知观察、工具／权限／执行版本变化沿现有规则停止或回退。此发布不扩展步数，也不宣称任意长文档都能完整接管。

新包包含 6 项载荷和脱敏认证摘要。旧四项证书保持 `release=file-v16` 与原字节，新两项绑定 `file-v17`；包版本与证书来源版本可以不同，现有 Python／TypeScript 校验器分别回溯原 manifest 并核对当前契约。`grants_execution=false`，种子不是用户文件的执行授权。新账号冷安装得到六项；已有账号补入两项，用户停用状态保留。

原始资料、真实原生事件、逐 HTTP 用量、旧版本、短片段、失败、恢复、独立认证材料及审计保存在私有实验目录。只发布 IR、哈希与脱敏证明，不提交 `.local` 或私有证书。完整研究编排器仍保留在本地，本 PR 的公开复现范围为种子完整性、跨语言准入、账号升级及失败守卫：
