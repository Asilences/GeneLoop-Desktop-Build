# 公共脱敏模块 R2：输入边界修复与冻结回归

本轮根据 [R1](privacy-benchmark-20261107-r1.md) 的错误开发，再冻结新规则复测三套基准。**这是开发后的回归评测，不是独立未见评价；工程通过和有限样例不能证明匿名化完备或 RSI 质量不变。** R1 文档、聚合结果与服务器私有记录保留，未操作正式服务、任务、原件或累计账本。

结论：确定的 JSON 包装与重复键缺陷已修复，中文误拒绝和部分身份类型有所改善，**隐私质量仍未通过验收**。中文正式集姓名完整遮盖率 58.44% → 55.14%，中文聊天总体未改善，聊天/英文的金标外遮盖与正文片段损失有所增加；凭证超时 39 → 89。不能用总体指标的局部改善掩盖这些退步。

## 修复与版本

- 产品规则 `d832be12fabc76fc995b358e15a110a506ba4711`；评测工具 `ca083357342fd1f7f4e8238d6f8f72add94ab95c`。与 R1 的数据、模型、阈值、标签映射和成熟评分器相同，规则冻结后未依实测调参。全部输入摘要、R1 金标及原生 Presidio 13000 条预测逐项一致，源文件哈希未漂移。
- Gitleaks 8.30.0 规则和二进制不变：前后扫描完整 JSON 包及其解码字符串/嵌套 JSON 文本，包含 NFKC 视图，完整原文只在内存拼接，避免转义隐藏匹配。保留 `--ignore-gitleaks-allow`、解码深度、工具失败和命中拒绝；不截断后放行。
- 标准库 JSON 的默认重复键行为会丢弃前值；嵌套原文却可能原样保留。通过标准 [`object_pairs_hook`](https://docs.python.org/3.12/library/json.html#repeated-names-within-an-object) 拒绝重复键（含转义同名键），解析深度失败也不再当作普通正文。合成低熵凭证控制在前候选真实复现“准入且保留原文”，最终版本拒绝；不依赖扫描器一定能认出弱密码。
- Presidio 2.2.365 / spaCy 3.8.7、中英文 small 3.8.0 不变。启用此前遗漏的上游证件/账户识别器，通用日期、年龄与组织归属仍不作为所有任务的身份字段。已有姓名/地址标签模式只替换值，减少吞掉标签和别名不一致。
- 用固定 `regex` 2026.9.29 的 Unicode 字素簇映射 NFKC 识别跨度回原文，未遮盖的代码、公式和标点保持原样。替代两次独立识别输出必须一致的拒绝条件；无法对齐仍拒绝。
- 协议词在正文中的完整词边界也保护；另修样本量 `n=128` 被 spaCy 当姓名的问题。这些保护仅过滤统计 NER，显式身份字段和凭证扫描继续执行。没有训练新的 GeneLoop PII 模型。

开发验证先有 57 项定向通过，再补 2 项真实扫描器检查；4 项检查覆盖修正的样本量、嵌套/全角凭证和显式身份字段。早期语义结果 24/24 准入但仅 117/120 不变量保留，定位后修复。候选 `f2af62cf` 的完整 Python 3134 通过/214 跳过、Node 1722 通过/9 跳过、smoke/Motif 通过，仍在独立补查发现重复键绕过；新增 6 项解析检查通过后，对最终版本重新执行完整回归。旧候选检出、回归和失败诊断均保留，不用工程通过掩盖隐私缺陷。

## 任务语义与入口

同一 24 条项目补充集：R1 准入 14/24、准入保留 64/68、计入拒绝损失后的总体可用覆盖 64/120；R2 **准入 24/24，准入不变量保留 120/120，全体可用覆盖 120/120**。准入身份标记字面残留 0，两个 secret 控制均拒绝，原输入摘要均不变。它是开发回归集，不是独立 benchmark 或真实 RSI 后继质量证明。

Paper/PPT 使用相同公开样本和 secret 控制：Web 结算函数/worker 与离线 CLI **14/14 一致，12 准入、2 一致拒绝**；原件摘要全不变。未启动 HTTP 服务或真实模型任务，不代替 Mac Coding/正式接收端产品验收；小样本不能外推所有大文件的时限与冷启动行为。

这 14 组是两个场景复用部分 benchmark 样本的接线检查，**不是通用 benchmark 总量，也不是全部入口证据**。13,000 条 PII 和 11,030 个凭证文件直接测不接收场景参数的公共内核；无需将同一条识别样本在每个宿主上重复后再冒充更多独立数据。另从最终完整回归的 JUnit 逐项核实：注册场景加 Chat/Coding/未来自定义 MCP 共 9 个场景，两个 Web 宿主分别 9/9，Web/离线/共享对照 9/9，公共投影任务语义 9/9，真实 SDK + 本地测试 Provider 1/1，SDK 关闭生命周期 3/3，均实际通过、没有跳过。

用户追问入口范围后另补 **10/10** 研究/导出边界检查：Python `check_entry_boundaries.py` 9/9、Node `check_construction_export.mjs` 1/1（位于 `scripts/privacy-benchmark/`），源码摘要及逐项范围见[入口回执](artifacts/privacy-benchmark-20261107-r2/entry-coverage.json)。Builder 的真实上下文准备、目标提案、Evolution 请求及工具返回、历史模型上下文及四个公开导出边界均调用真实公共内核。operation-library 在合成注册库入口拒绝，未创建输出且原 payload 字节未变；construction-library 使用真实只读 CLI，合成可信 seed 私有导出可读取，公共导出拒绝、stdout 为空、原 seed 未变。online manifest/efficiency registry 使用注明的上游产物装配替身，模型回调/有限预算 gate 也为测试替身，没有真实模型请求。这些检查验证接线和输出前拒绝，不验证真实认证库的质量或全产品 E2E；Mac 与正式接收端边界不变。补充检查没有加入或修改本轮基准金标/规则，不混入 benchmark 评分分母；最初 8 项回执独立保留。
