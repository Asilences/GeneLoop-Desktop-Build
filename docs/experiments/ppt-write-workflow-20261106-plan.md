# PPT连续写页、修订与受管交付实施

实验ID：`ppt-write-workflow-20261106`。基于PPT97/Paper99未提交候选；保留上轮源码、库、所有失败与费用。本轮尚未取得效果结论，不修改正式服务。

## 实施与学习边界

1. 盘点允许学习的真实普通轨迹。连续写页、参数修订、备注和交付分别统计；E/R与`learning_eligible=false`材料不回灌。
2. 扩展类型化工具契约。契约声明输入、输出、写入对象和版本要求，不写制作顺序。候选的节点、顺序与绑定从成功调用中发现，外部内容显式参数化，科学内容不作缓存常量。
3. Python编译写入程序，由两个独立来源支持、第三来源认证；另做当前实现的隔离实际执行认证。未知Shell、并行依赖、失败、语义选择和无法绑定的未来输入均为边界。
4. TypeScript执行器接收模型一次提交的当前内容。预检整个调用后按认证IR顺序执行；修订核对当前页面SHA，保留其他页，失败保留进度、不给写操作自动重试。学习程序与人工通用执行器分别计来源。
5. 被选定组件的制作与交付在执行层内完成。参数可修，明确不适用/用户重设计可以有记录地退出；不把正常诊断变成自由重写整稿。共同质量底座继续用于普通组。
6. Windows/macOS复用同一解释器，平台、原生schema与执行包分别认证，不搬用Linux证书。保留本机工具/服务器模型接口，诊断与真实模型验收分开。

## 最小验证

先复用历史材料；若没有足够类型化写入证据，明确记录缺口，只补少量正常材料任务，不能手填顺序冒充发现。完成执行、取消、权限、版本失效、局部修订及失败恢复回归后，冻结候选，再做少量独立真实任务，全部关闭学习。

对照使用相同模型、题面、资料、工具质量底座和验收。制作包括弃用、失败、重试和恢复；学习/认证/Judge另列，保留实际请求、输入输出token、时间和费用。Judge是辅助，科学数字/条件、备注与最终稿需核查。效果失败不增加任务挑选正例。

真实模型调用沿已授权Flash/off、393216、null额度及原累计账本；付费前另说明预计投入。源材料、轨迹、账本与成品在私有`.local/`；报告只保留可共享摘要。当前不提交、推送或正式发布。

- 正常材料为原先明确允许的Adam、BatchNorm、PPO三篇论文，每份两页、一次预先规定的标题和备注修订。初稿与修订按同一个原论文来源归组，不当成独立来源。材料清单SHA256为`31cc2bf5c042e96f146845f7260e6fc7b31abc7a9c8ced9b5d42916ffd1feb77`。
- 新来源留出为GLU Variants Improve Transformer和RoFormer，各两页、同会话一次预定修订。B0/B2题面一致、学习关闭，顺序E01-B2、E01-B0、E02-B0、E02-B2。评测清单SHA256为`fd2f232dfbac779e85634c79d1e54f4678d99272eaf80d538725a364e9e834c1`。只评价这两个匹配场景，不外推一般PPT。
- 原测试入口没有逐轮预算路由，第一次修订在付费前被拒绝。配置纠正期间旧会话被标记为旧工具集，故保留旧L01并在正确配置下补同题材料，不将其作为新来源。后续L02/L03因版式组件被内容事实错误误停用而走了普通Bash路径；原稿和费用保留，修复后只补同两题，不新增选题追求正例。
- 第一份成功材料中确有Adam/Adagrad的错误概括，Judge初稿拒绝、仅改标题后的同内容稿却通过，两份原评分均保留。人工核查不能用后一分数覆盖前一错误。布局作用域与任务质量分开：错误任务仍不合格、不能计合格使用或降费晋级；仅视觉/可用性通过的已认证纯版式组件可保留其原有版式范围。
- `severity=review`是回执要求看图的提示，不能当成阻断错误，也不能直接忽略。只有真实轨迹覆盖全部当前PNG时允许学习；运行仍返回全部图像和提示给模型。错误、未知级别和不完整预览继续拒绝。该守卫和参数文件固定是人工基础设施，不称为RSI发现。

## 认证和效果判定

历史认证先验证两个来源的观测结构能在第三来源中重放绑定，范围标记为`independent_observed_write_binding_replay`，保留`runtime_followup_required=true`。接着必须用学得IR实际调用本版本工具，完成页写入、备注、Office交付、预览和版本核验。两种证据分开记录，不把历史绑定检查称为真实执行认证。

后继B2必须在实际任务事件中调用学得程序，且组件采用回执中的PPTX摘要等于最终交付摘要。只在工具目录出现或试运行成功均不算采用。修订另核对未指定页面和备注的版本不变；两组都保留失败、重试和弃用费用。单次执行内部无模型请求不等于已验证省掉多少请求，端到端比较以逐任务账本为准。

制作、材料/发现/构造/认证、Judge分别列账；真人修订分钟、机器维护成本和账单实付未知时如实保留。不得拿学习支出混进B0/B2，也不把它从长期投入摊销里隐藏。没有合格收益就报告未证明，不追加题目挑选正例。
