# PPT 受控制作与正常轨迹学习

## 问题与假设

上轮组件试用后重做，未证明稳定收益。上游 executor 要求整页手写，与页面程序接口冲突。字体校准与反复诊断占用模型决策，交付还可绕开共同检查。

本轮先将稳定的字体测量与交付交给宿主，统一运行规则，并记录组件进入最终页面的证据。假设这些修改能减少无依据诊断，保留明确缺陷修订和科学内容判断。普通脚本收益与学习结构收益分别报告。

## 实施范围

- 锁定上游只读包，新增宿主 `runtime-policy.md`，原生 Skill 和 MCP 入口同时返回该规则。
- `prepare_ppt` 根据规范、计划文字、实际字体文件、Python包与宿主环境版本校准常规/粗体角色，复用相同版本。
- Generate 统一 `finalize_ppt`，最终发布核验当前源文件与成功交付回执。原生往返编辑保留其路径。
- 已认证组件可直接安装到项目页面，保留成功工具调用、参数摘要及页面SHA，纳入正常轨迹材料。
- 固定活动还包括分组边界注释计算。脚本仅更新可确定的data-pptx-bounds，保留实际文字、坐标和颜色，复用锁定检查器的文字度量；遇到真实重叠、越界或不支持的几何交回现有检查。错误回执直接返回逐页具体原因。
- 原生present存在时只使用实际交付文件作为学习材料，失败中间稿保留在私有诊断目录。
- 自动学习先收集正常材料。模型生成、认证、后继调用和最终成品来源分别验收。未认证候选不得进入执行库。

## 验证次序

1. 无模型回归覆盖规则一致性、诊断转交、字体/文字变化失效、旧稿拒绝发布、组件安装和正常轨迹来源认证。
2. 独立服务器候选执行真实小规模任务。使用 DeepSeek Flash、thinking off、393216容量；累计费用/请求不限，沿用原账本。学习与Judge单列。
3. 学习gate要求正常完成轨迹自动准入、候选认证、后继独立任务实际调用和成品来源匹配。质量按共同任务要求，Judge为辅助。
4. Gate通过后才启动较大批自然任务。计划24项，覆盖单/多论文、自然语言页数、图表解释、模板参考与局部改稿，训练和留出按来源隔离。小规模训练包含前一份成品作为下一任务视觉参考的自然场景，通过输出/输入SHA依赖发现复用机会；训练任务不进入后继成本比较。全部调用真实模型，模拟指任务构造，不使用固定回复。

## 边界

本文件保留实施前计划。制定时批量任务尚未启动，后续学习验证、真实负例及24题启动情况见[结果记录](ppt-managed-learning-20261104-results.md)。费用与质量以该记录为准，工作区既有改动和历史负例保留。
