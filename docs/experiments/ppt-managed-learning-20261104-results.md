# PPT 受控制作与正常轨迹学习结果

## 当前结论

字体校准、页面边界注释和 Generate 导出已集中到宿主脚本。普通任务中的重复字体探测、成品字符框诊断、独立 CairoSVG/DPI 页面预览由 Harness 守卫引导到共同入口。真实可见缺陷和科学内容仍需要模型判断。

两条正常任务轨迹自动产生了一个参数化页面程序，经过隔离执行认证，并在独立 ResNet 任务中实际调用、进入最终 PPTX。该次使用的来源统计漏记了失败导出中已完成的注释修复，已通过独立审计副本重算确认，原始事件保持原样。新运行代码支持跨回执追溯这类修复。

24 项自然场景材料任务已启动，当前按队列串行执行。本记录的小规模验证已结束，批量任务结果继续追加。当前程序保持 probation，质量费用晋级仍待后续合格配对证据。

## 问题、修改与入口

| 问题 | 本轮处理 | 主要实现 |
| --- | --- | --- |
| 完整 Skill 要求整页手写，与程序复用冲突 | 原生 Skill 与 MCP 同时提供共同运行规则，保留锁定上游原文 | `scenarios/ppt_master/runtime-policy.md`、`server.py`、`geneloop_native_work.ts` |
| 重复测量字体、字框和 DPI | `prepare_ppt` 校准常规/粗体角色，按字体文件、环境和规范版本缓存 | `ppt_preparation_runner.py`、`ppt_delivery_pipeline.ts` |
| 绕开统一导出和反复独立渲染 | Generate 官方检查、导出、项目页预览转交 `finalize_ppt` | `ppt_delivery_pipeline.ts`、`ppt_delivery_runner.py` |
| 手工调整非绘制边界注释 | 脚本计算可支持几何的边界，保留文字、坐标和配色 | `ppt_annotation_repair.py` |
| 浅底白字、缺字及复杂背景误报 | 实际字体与对比度预检，不确定路径背景保留视觉检查 | `ppt_design_preflight.py` |
| 失败草稿混入学习材料 | 原生 present 优先选择实际成品，宿主保存源页回执 | `harless_comparison_artifacts.ts`、`ppt_component_learning.py` |
| 离线认证接受 schema，在线加载回退 | 统一局部 `$defs/$ref` 展开与校验，认证结束用在线加载器复核 | `ppt_component_schema.ts`、`certify-artifact-motifs.mjs` |
| 组件只能新建，无法调整参数改原页 | 增加 `expected_page_sha256`，版本一致后原子替换目标页，保留来源 | `ppt_component_tool.ts` |
| 执行接口变化后沿用旧认证尝试标识 | 学习实现签名覆盖组件工具、schema、渲染和共同交付代码 | `ppt_program_learning.py` |
| 失败导出已补注释，下一次成功导出漏记组件使用 | 沿同项目、同源页、宿主证明的注释修复链核对来源 | `recordPptDeliveryReuse` |

正常页面学习入口为 `ppt_page_learning.py`，由已有 Web 任务结束后的学习 worker 调用。重复版式或前稿成为后稿视觉参考形成候选信号。模型返回 Python 程序、参数 schema、原页参数和另一论文参数，再经现有 Artifact 沙箱认证。后续任务冻结加载已认证库，经 `create_ppt_page` 调用。

## RSI 的实际证据与限制

- 程序 `artifact_379059df77ec7c1e7cdec791` 来自正常交付页面。模型候选源码经过多次验证器修复后保持不变，提案生成累计1次。字体、schema、渲染一致性与来源追溯的修复包含开发者参与。
- 认证经历了技术属性被误当科学常量、参考字体/透明画布不一致、在线 schema 不支持三类失败。失败记录保留。认证比较可见文字、画布和实际像素，仍保留原严格门槛。
- 同一次提案提供的另一论文参数用于不同输入执行认证。后继 ResNet 是独立真实请求，实际加载库、模型看到目录、调用程序、最终源页匹配分别有证据。
- G03 发生手工 SVG 修订，完整组件交付使用计数为0。G04 的 SVG 由组件生成，宿主随后只补非绘制边界注释。统计修复在独立副本追溯该链路，确认最终成品使用1次，原始任务日志未改写。
- 最后一次接口变更的重新认证由开发者调用现有编译器完成，禁用新提案凭证，新增模型请求0。初次学习由正常任务 worker 自动触发。后续批量任务加载新的冻结库，实际在线统计继续验收。
- 当前库保持 probation。正常材料持续收集，当前代候选的扩大生成和 active 晋级仍受既有独立验证约束。尚未形成任意版式、任意图件的通用程序学习能力。
- Graph 保留原读取载荷。新正常轨迹尝试未认证出新的受支持衔接，原拒绝记录保留。新页面程序与 Graph 的证据分别统计。
