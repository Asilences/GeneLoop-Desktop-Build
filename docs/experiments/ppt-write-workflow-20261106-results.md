## 真实发现与失败

三篇原论文产生15条可学习正常轨迹，按原论文归为3个来源；初稿和同稿修订不算独立来源。观察到了连续修订两页再交付的局部候选，但**跨来源认证写入程序0个**，没有后继真实替代和降费证据。

主要问题及处理：

1. 旧测试入口没有逐轮预算路由，第一次修订在付费前被拒绝。接通仓库已有路由并兼容旧`sss-`会话；配置纠正期间原会话被登记为旧工具集，保留失败后另存同题恢复材料，原累计账本不清零。
2. 正常模型使用参数文件，旧学习条件只接受直接内容。现按原生工具互斥契约接受两者，在写入前固定当前文件内容再计算执行版本。
3. 机械通过仍可能有`severity=review`，旧空列表条件漏学。仅对此类提示保留完整观察证据和后继判断，阻断错误、未知级别仍拒绝。
4. Adam/Adagrad结论概括错误使纯版式组件被停用，后两题退回普通制作。现仅对明确版式作用域区分内容失败和布局失败：错误任务仍不合格，不计合格使用、收益或晋级；用户负反馈、视觉/可用性失败继续撤回组件。
5. Judge对初稿中的同一错误概括和仅改标题后的稿件给出相反判定。两份原评分均保留，不能挑较高的一次当作通过。
6. 写页/交付之间混有看图、哈希核对和实际修改SVG/备注的脚本。不能一概跳过，也不能手填流程补足证据。最后108观察抽象只做确定性预检，仍未得认证候选，未晋升；六份实验源码/测试另存私有目录，当前代码恢复为完整回归过的107。
