## 验收与费用口径

1. 全部计划样本均进入分母。未完成、失败、含在途用量、成品歧义或缺页分别记录，不只选择成功或低费运行。
2. 原生可编辑文字、备注、页数、PPTX/PDF/PNG 真正渲染；多轮检查原稿归属、目标页变化、非目标页文字/XML/像素与图件来源。机械通过不等于科学或视觉合格。
3. 使用原十分制六维度 LLM Judge，检查原论文文本及冻结页像素、实际全部成品页像素和备注；缺少证据为 unknown，不给未知项重归一化。Judge 不知道 B/O，不能代替独立人工评审。
4. 按本轮 runtime task ID 统计真实请求、命中/未命中输入及输出 token、所有 attempt、失败/恢复费用和用时。生成与 Judge 分账，不能把共享累计账本的全局总额称作本轮开销。
5. 程序发现/认证的模型请求与 CPU 开销单列；程序复用和 `verified_skips` 分开。人类评审/修订分钟与服务商实付未知时保持 `null`，不填零。
