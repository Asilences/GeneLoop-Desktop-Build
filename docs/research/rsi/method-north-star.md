# GeneLoop 方法北极星

GeneLoop 的研究目标分为两个层级：**P0 效率 Self-Improvement** 是最低方法交付，**P1 性能 Recursive Self-Improvement** 是进一步突破。两者共享能力池，但各自的效果必须分别验证。

## 核心算法：两条循环共享同一能力池

基础循环从正常任务的真实执行经历中发现重复工作，自主构造并认证可执行抽象，再在后继任务中按输入、版本、证据和权限守卫调用它。结果与失败回到学习材料，推动已有抽象的修订。Evolution Agent 可以利用同一能力池与反馈，改进抽象边界、能力构造和求解策略，进一步帮助创造下一代能力。

## 最低研究目标与研发优先级

GeneLoop 追求效率驱动的递归自我改进，但完整 RSI 不应成为基础效率改善的前提。**即使暂时无法实现性能层面的 Recursive Self-Improvement，GeneLoop 也必须优先实现可靠的 Efficiency-Driven Self-Improvement。**

P0 的最低成立条件是：Agent 从正常执行经历中**自主发现、构造并认证有实际价值的可执行抽象**；后继任务真实复用该抽象，以相同质量完成任务，并减少原本需要 LLM 反复承担的工作。Agent 还应能根据新证据核验、修订或停用已有抽象。这是由 Agent 自身学习行为产生的效率收益，不能只以 Token 数下降定义。

例如，人工预置一个工具，使模型请求从 100 降到 60，是执行优化；Agent 从自身经历中发现重复工作，学出可靠结构，让后继任务在同等质量下从 100 降到 60，并能在新证据出现时调整结构，才开始体现效率自我改进。进一步证明已有抽象帮助 Agent 发现、创造和验证下一代能力，属于 P1 的研究问题。

以下证据不能单独替代 P0：

- 人工编写的缓存、固定脚本或预置工具；
- Motif 编译成功、认证通过、能力调用回执或能力数量增加；
- Evolution Agent 修改 Prompt、Task Strategy、提出新目标或生成更多候选；
- 只报告 Token 降低，而没有同等质量下的真实模型工作与任务成本对照。

每轮实验分别记录：真实模型工作是否减少，合格任务的成本是否降低，以及学习、认证、检索、验证、修复和失败成本能否在后继任务中摊销。局部前向节省与累计净收益分别报告；代理估费与账单实付分别报告。研发优先建立**正常执行 → 自主学习 → 后继实际复用 → 质量与效率反馈**的完整闭环，再研究 Evolution Agent 如何改善抽象边界、能力构造和下一代能力创造。

如果 P1 暂无可靠效果，可以冻结这部分研究，保留已验证的效率 SI 作为核心方法与产品能力。如果 P0 仍未成立，应明确认定核心方法尚未达到最低目标，优先定位真实阻断；不能用更复杂的 Evolution 机制或更多候选替代实际效果。

最终优先级是：**真实效率 SI → 可持续的效率收益 → 后继能力创造 → 性能与效率共同驱动的 RSI。**这是研究优先级，不要求每次探索 P1 前先证明累计净利润。不同层次可以并行研究，但证据必须分别成立。

本要求适用于核心算法与相关研究实验；独立的桌面、前端及常规产品开发仍按各自任务验收。
