# preview.20 Windows 首次与覆盖安装实测

## 结论

2026-11-08，在用户这台 Windows 机器上使用已交付的原始 `0.3.0-preview.20` EXE，实测旧版覆盖安装和空目录首次安装。应用安装已经明显缩短，但完整工具的首次准备仍需数分钟，不能把小安装器退出的时间当作六场景全部可用的时间。

| 实测项目 | 秒 | 说明 |
| --- | ---: | --- |
| preview.15 → preview.20 覆盖安装 | 55.450 | 原应用 D 盘目录；含旧版备份、引擎、新文件写入、注册和清理 |
| preview.20 空目录首次安装 | 17.006 | 官方卸载器移除应用本体后，注册为空、目标为空；账号数据保留 |
| 六个工具分包首次准备 | 370.386 | C 盘正常用户工具目录；本地导入、解压、25,666 文件逐 SHA 校验与就绪标记 |
| 首次应用安装＋首次工具准备阶段之和 | 387.392 | 约 6 分 27 秒；不是从双击到可用的一段连续墙钟记录 |
| 已就绪工具重新打开并调用准备检查 | 30.336 | 不重解压；包含 Store 构造和 prepare 的文件存在性检查，不是应用启动时间，也不是重新逐 SHA 校验 |

首次工具目录原来没有缓存文件。全部六包下载体积 322,160,334 字节，展开 1,431,327,174 字节。本轮使用本地分包，不包含网络下载、用户手动操作或 UAC 等待；Windows 版本 `10.0.26300.0`。H 盘为安装包／工具包源，D 盘为应用，C 盘为正常用户数据及工具目录。空目录安装是本机应用首次安装条件，不代表全新操作系统或清空磁盘缓存。

覆盖安装阶段的新载荷为 128 个文件、792,013,936 字节，实际解压／写入探针 12.137 秒；引擎结束为 27.624 秒，最终清理完成为 47.150 秒。外层启动至退出为 55.450 秒，报告覆盖全过程，不仅取解压值。空目录安装对应解压探针 7.713 秒、清理完成 16.727 秒、外层 17.006 秒。

此前用户反馈的 8–12 分钟是历史完整安装体验，与本轮分离工具准备后的测量条件不同，不能据此计算精确提速倍数。此前 H 盘隔离工具恢复 82.691 秒也不能替代本轮 C 盘正常目录的 370.386 秒。

## 执行与数据保护

- 安装器 SHA-256：`10bd77666aea7b2a59d8ee9a4dcc5040a556c3031c443a1be22fbf93876accc3`，与交付清单一致；没有重打包或修改原安装器。
- 从原已安装 preview.15 开始，先真实覆盖到 preview.20；再使用新版本的官方卸载器 `/S /allusers`，不传 `--delete-app-data`，构建配置 `deleteAppDataOnUninstall=false`。确认注册和应用目录为空后首次安装到原目录。
- 全程没有停止用户进程。原应用已退出；最终保留安装好的 preview.20。原账号／应用数据 203 个文件，在覆盖、卸载和首次安装三个阶段逐 SHA 一致；工具准备只新增正常工具目录。
- 工具准备直接运行已安装 `app.asar` 中的 `ToolPackStore`、已安装的解码器和实际六包清单。最终 toolset 为 `e7667b8fc863e4efb820cf440ee087e7cd464295545509e0610e957349a8191f`，在正常用户目录 ready；不是开发副本或 H 盘已展开工具。
- 已就绪复查的 30.336 秒说明重复文件扫描仍有成本。工具准备主要面对资料／模板 13,714 文件和 Python 9,923 文件，两者合计 23,637，占全部文件约 92%。下一步应关注小文件落盘、逐文件校验及重复存在性扫描；没有证据将该耗时直接归因于杀毒软件。

私有测量、配置快照和进程日志保留在桌面工作区 `.local/install-benchmark-preview20-20261108/`：`run.ps1`、`result.json`、`fresh-baseline.json`、各阶段 trace、`tools-result.json` 与 `tool-preparation-phases.jsonl`。原账号文件仅保存本机摘要，不公开内容。
