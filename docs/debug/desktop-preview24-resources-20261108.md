## 实现

- `general_tools.py`发现目录改为只读登记元数据及已取得的目录提示，不再逐个连接所有提供方。实际Schema仍由选中的`describe_tool`、准备和执行校验；未知提供方不因名称筛选消失，未连接可用性明确为未知。空`tool_name`可取得单个服务的完整目录。
