# GeneLoop Desktop 0.4.0 本地交付

## 行为与范围

- 基于preview.27，版本改为0.4.0。左下鱼缸、A结构演化、B能力分布默认展示当前账号可见的总Motif库，包含场景目录、账号学习来源及已登记的工作区回执。切换工作区不切换总池；斜箭头仍打开居中可放大详情，增加场景/来源/状态筛选，全局Motif页也默认总库。
- 按能力ID去重，当前账号学习目录优先于场景目录，再优先于工作区历史快照；同优先级按来源时间，完全同级的状态冲突保守展示并保留来源差异。认证不代表本机可用性。复用仅按收到的实际invoke/applied回执去重，不累计重复导出；没有回执保持未知。来源不可用显示不完整提示，不伪造完整计量或收益。
- 工作区右栏改为已使用Motif和实际回执，维持任务/会话范围。层级仍按原协议如实显示未知；示例不混入账号结果，不从工具依赖推导Motif组合关系。
- 保留GeneLoop字标、朱红和分形图形，统一输入框、按钮、弹窗及菜单的圆角；新增左侧快捷导航、聊天边缘逐轮刻度、顶部对话目录与右侧工作台。工作台连接原有交付文件、轨迹、工作区、总库及重新连接，不创建新的执行器或工具服务。
- 参考用户提供的Codex桌面截图，并核对[官方开源入口](https://github.com/openai/codex)。本轮自行适配GeneLoop界面，未复制OpenAI桌面资源或商标；原Lucide和字体许可保留。
