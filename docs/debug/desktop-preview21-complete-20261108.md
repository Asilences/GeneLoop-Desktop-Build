# preview.21：默认完整离线安装，工具随安装一次就绪

## 产品决定与范围

preview.20 的小安装器首次仅17秒，但正常用户目录中全量工具准备仍370秒，两个处理阶段合计约6分27秒。这只是把大量等待转移到了安装后，不适合作为正常用户的默认入口。

preview.21 将默认 `npm run dist` 改为显式 `--complete`。当前六场景工具压缩分包合计322MB，仍适合完整离线交付；完整包把工具一次安装到应用资源目录，完成后无需下载、导入或全量准备。`npm run dist:lite`／`--lightweight` 只保留为主动选择的小包构建；底层 CI 原有显式环境入口兼容，不为此改服务或执行器。

PPT仍只制作／编辑及核验，语音扩展不恢复；其余场景、模型认证、Motif与隐私内核不改。Mac使用同一默认完整构建入口，但本轮只生成并实测Windows，既有Mac DMG仍是原preview.20版本。

## 实际交付与安装

- Windows `GeneLoop-Desktop-0.3.0-preview.21-x64-Setup.exe`：**754,715,648字节**，约755MB；SHA-256 `228e04308124adb875e8af79a9c20d7b9696db71779d19134cd761aceaf0dfba`。
- 应用加工具实际载荷25,791文件、2,217,763,502字节。完整包采用当前原生ZIP直接解压路径，与六分包7z的压缩方式不同，因此不把267MB小安装器＋322MB分包的和当作完整安装器实际大小。
- 本机从preview.20覆盖到preview.21，外层安装器启动至退出 **75.107秒**，含全部工具写入。内部提取完成41.393秒，引擎完成62.669秒，清理完成62.872秒；报告外层总时间，不只报告局部解压。
- 原已准备工具在C盘用户目录，本次完整包直接写入D盘应用资源目录，不依赖旧用户工具缓存。当前六场景工具随安装就绪，不再进入安装后的统一准备流程。
- 原账号／配置203文件在安装前后逐SHA相同。最终本机已安装preview.21；旧preview.20安装器和工具缓存保留，不清空用户数据。

这是本机实际覆盖安装，不是全新系统首次安装；没有另做完整包空目录安装。计时不含下载安装器、UAC等待或人工操作。与preview.20两阶段测量的工作流／目录不同，不计算严格提速倍数。

本地交付在仓库私有 `.local/desktop-releases/0.3.0-preview.21/windows/`，只需要该EXE，不需要另取六个工具包。没有上传安装器或发布Release，没有启动Mac Actions／消耗Mac额度。

## 实现与完整性

- `package.json`／`build-installer.mjs`：默认完整入口和显式小包入口；拒绝同时选择两种模式。完整入口不受残留 `GENELOOP_DESKTOP_TOOL_PACKS=1` 影响。
- `electron-builder.config.cjs`：完整构建校验当前平台／架构、PPT制作范围、GeneLoop Skill和默认Office Kit；排除生成缓存，不改原工具源。打包裁剪回执为0文件／0字节。
- 实际完整载荷与已验收六分包的 **25,666个工具文件逐SHA一致**，无缺项／差异；7个运行时关键入口与源码一致。完整工具包括场景／材料、Python、Office、浏览器、媒体和格式转换。
- 完整包没有 `resources/tool-packs.json`，现有 `localToolDirectory()` 直接选择 `resources/geneloop-tools`；启动不创建 `ToolPackStore`，因此不触发首次全量准备页或25,666文件的重复存在性扫描。手动打开工具状态页时，已随包提供的导入／准备操作禁用。
- 仍使用既有NSIS注册、提权、旧版事务备份／回退和.NET Unicode直接解压。完整载荷SHA在写入前校验，路径越界、错误SHA、目录链接拒绝及复用守卫保留，没有另造Agent或替换六场景接口。
