# Windows 0.4.1：本机学习、脱敏与自动收集

## 本轮行为

本机工作区的正常执行事件写入当前服务器、当前登录账号隔离的本机目录。任务终态后自动调用现有 Python 隐私投影、Presidio/Gitleaks，再进入已有的轨迹挖掘、只读编译、独立结构认证及执行器。学习和收集没有开关；首次说明固定处理范围。任务内容仍按原用途交给云端模型，收集端只收到不含正文、参数、路径、原工具名或会话 ID 的受限流程对象。

当前本机可执行学习范围是受授权的材料固定与读取等只读流程；两个独立经历训练、第三个独立经历留出，重复输入与同一会话不算新增独立证据。后继 Agent 可调用账号私有 `local_motif_list/run`，实际使用本轮文件和参数。未知/写入工具是屏障，复用经历仅作反馈，不用自己的复用轨迹消除或自证原证书。结构认证不等于质量、费用收益认证。

RSI/脱敏失败、超限样本和收集不可用不取消正常 Agent 工作，也不回退上传原件。原始任务副本保留 90 天、派生学习副本保留 30 天；源版本与代码不匹配的能力不可复用。三卡当前仍展示已有的内置及服务器库；本机私有学习状态在“数据与隐私”查看。各场景完整 Web Builder/学习策略及三卡私有库汇总不在本轮只读链路中冒充完成。

## 接收与兼容

- 新 `POST/GET /api/harless/rsi-collected-objects` 使用现有账号登录和同源校验。只有严格字段的 `geneloop.rsi-collected-object/v1`，最大 256 KiB，保留完成/失败/取消/中断结局。
- 对象 UUID、请求体摘要和持久回执绑定。网络响应未知或应用重启后先查原 UUID；同 ID 同内容不重复落库，换账号不可查询。
- 常规客户端只使用当前服务器 HTTPS；HTTP 限显式回环诊断。接收端尚未部署时本机保留待发状态。
- 桌面模型 lease 的 `localRsiTools:true` 声明新只读工具名；旧网关不声明时不发送未获准工具定义，学习与脱敏继续。
- 后端源码与桌面代码一起在 PR171。V100 仅更新既有隔离试用网关；正式 `geneloop.ai`、main 和其他正式服务未部署或合并。
- 现有证书未修改；网关新增独立路由后，仅登记核对过的精确兼容摘要。原 PPT/论文注册库继续加载。
