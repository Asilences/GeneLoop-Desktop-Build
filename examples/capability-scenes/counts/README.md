# 非视频场景适配诊断

这是通用Capability流程的第二种适配样例，不是生产Data场景。Python子进程真实执行分组计数，独立检查器复算JSON产物；任务、提案、原语认证与权限是明确的诊断夹具。不要把`diagnosticHost`连接生产用户会话。

运行：`npm run rsi:efficiency:check`。`tests/test_capability_scene.py`覆盖两条原生记录→共同发现器→共同控制器→此适配器发布→共同Store→后继任务→反馈，模型步骤使用诊断提案；`tests/test_capability_cycle.mjs`覆盖共同发布生命周期和失败保护。

`adapter.py`只实现记录解释、验证输入冻结和原生发布桥接；其余逻辑继承公共基类。`runtime.mjs`和`publish.mjs`是这个示例的原生执行/检查部分。真实场景须替换这些诊断权限和输入，接自己的已有原生后端与质量标准，不能复制合成认证当成真实认证。接入协议见[跨场景协议](../../../docs/research/capability/capability-scenes-v1.md)。
