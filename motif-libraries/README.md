# 产品 Motif 运行库

| 场景 | 当前公共包 | 用途 |
| --- | --- | --- |
| PPT | `ppt-master/` | 固定来源、转换与读取的认证流程 |
| 论文校对 | `paper-web/` | 上传文档的同版本第一页读取流程 |
| 数据报告 | `data/` | 已认证的报告回执续接 |
| 文件管理 | `file-management/` | 当前公开种子及认证证据，发行号记录在清单和证书中 |

网页场景由 `config/harless-scenes.json` 注册，文件管理独立加载公开种子。论文 Web 原生入口的 Motif 执行仍取决于相应的运行认证。视频通过独立的发布库接入，没有内置编号包。

同一运行库仅在当前分支保留一个发行包。升级时一并更新注册引用和认证记录。要复现实验、导入旧公开包或重放退役的重导出脚本，请检出对应的历史 Git 提交。文件管理的新包先生成到 `.local/public-file-seeds/`，通过发布检查后替换固定目录。私人原件、上传内容、轨迹和凭证留在私有运行区。
