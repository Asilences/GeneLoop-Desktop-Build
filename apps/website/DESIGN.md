# GENELOOP 平面与视觉设计规范

版本：1.0 · 2026-11-06
基准：最终工业分形官网，分形并排为默认构图，空间不足时采用文字叠加。

本规范供品牌设计、网页设计、演示材料与平面延展使用。标注为“官网基准”的数值来自当前实现；印刷与新物料的尺寸建议属于延展规则，不代表已有成品。

## 1. 视觉主张

**冷白为底，墨黑构架，朱红推进。**

GENELOOP 的视觉表达围绕经验、能力与递归展开：用有规律的结构表现积累，用连续路径表现演进，用少量强调色标记正在发生的变化。

三个判断标准：

- **清楚**：读者先看见主张，再理解关系，最后找到行动入口。
- **有秩序**：文字、图形与留白服从共同网格；相同角色使用相同排版规则。
- **有生命力**：结构可以增长和递进，变化应缓慢、连续、可追踪。

## 2. 色彩

官网采用 sRGB。新物料以以下色值为基准，不从历史样式中的早期配色取色。

| 角色 | 色值 | 用法 |
| --- | --- | --- |
| 主背景 | `#FAFBFB` | 大面积底色与留白 |
| 顶栏背景 | `#F5F7F7` | 导航与辅助分区 |
| 品牌底板 | `#EEF1F2` | 标识区域或需要轻微区隔的底面 |
| 主墨色 | `#272B2E` | 标题、正文重点、主要图形 |
| 次级文字 | `#6B7378` | 说明文字、编号、辅助信息 |
| 结构线 | `#D9DDDF` | 必要的分区边界与路径底线 |
| 强调色 | `#AD4C39` | 橙红／朱红，强调短语、行进路径、交互重点 |

以冷白和墨黑建立主体，强调色用于少量关键位置。不要用大面积朱红铺底，也不要把冷白改成米黄、深灰或钢蓝。

平面延展先按上述 sRGB 目标设计，再使用承印条件对应的 ICC 配置转换并打样；不指定未经打样的通用 CMYK 数值。

## 3. 标识与字标

使用 [棕金丝带标识](assets/brand/geneloop-mark.svg) 与大写 `GENELOOP` 字标。SVG 保持原比例和透明底。

- 标识与字标以**可见墨色轮廓**校准高度和垂直中心，不能只对齐图片外框。
- 官网顶栏以标识 `1.585cap`、向下光学位移约 `0.83px` 为现有基准；其他尺寸应重新检查轮廓。
- 不拉伸标识，不加投影、发光、立体挤出或额外底色胶囊。
- 平面延展建议：以标识可见高度 H 为单位，四周至少保留 `0.5H` 净空；独立标识在数字物料中建议不小于 24px。

## 4. 字体与授权

| 用途 | 字体 | 原则 |
| --- | --- | --- |
| 英文导航、编号和功能标签 | IBM Plex Mono | 用等宽节奏表现工业秩序 |
| 英文标题与正文 | IBM Plex Sans | 首页首屏标题用 500 字重，研究与愿景标题用 450 字重 |
| 中文标题与正文 | Noto Sans SC | 中文采用自然字宽，不强制伪等宽 |
| 辅助展示字体 | Space Grotesk | 已随官网提供，延展时使用；同一层级保持一致 |

四款字体均随包附带 **SIL Open Font License 1.1**，允许商业使用。分发字体时保留对应 OFL 文件；修改或重新命名字体需遵守其许可证条款。授权入口见 [FONT-LICENSES.txt](assets/fonts/FONT-LICENSES.txt)。

首页展示标题的彩色词沿用所在标题的字重。其他中文强调采用正体、600 字重。不使用软件倾斜模拟中文斜体。英文可以按语义强调，但一个完整概念应共用颜色、字重与层级。

### 官网字号基准

| 角色 | 桌面基准 | 窄屏基准 |
| --- | --- | --- |
| 首屏大标题 | 随可用内容宽度连续缩放 | 保留同一字体与缩放逻辑 |
| 研究／愿景展示标题 | 48–52px，平板随宽度缩小 | 30–34px |
| 产品卡片标题 | 24px | 按空间自然换行 |
| 正文 | 18px | 保持可读性，不靠整体缩小容纳内容 |
| 引导句／文章正文 | 22px | 约 20–22px |
| 愿景说明 | 20px，行高 1.8 | 自然换行，保留语义分行 |
| 主导航／首屏按钮 | 18px | 18px |
| 四阶段标题 | 英文 22px／中文 24px | 英文 18px／中文 21px |
| 页脚口号 | 18px | 17px |
| Join us 章节标题／编号 | 24px／18px | 22px／16px |

不同字体按字面量感校准，不要求中文与英文机械地使用同一像素值。正文行高通常为 1.65–1.85；大标题按字形单独调整，必须给下伸部留出空间。

## 5. 网格与留白

采用 4px 的间距基础单位，优先使用 `8 / 12 / 16 / 20 / 24 / 32 / 40 / 48 / 64 / 80px`。

官网基准：内容最大宽度 1440px；大屏左右通常各留 56px，中等窗口约 32px，手机约 18px。并排首屏两栏比例为 `1.14 : 0.86`，栏间距 40px。

- 每段内容至少与一个主网格边界对齐。说明文字应归属于标题或图形，不能悬在独立位置。
- 同级章节共用编号列、标题字号和行高。长标题自然换行，编号对齐首行，不随总文字高度居中漂移。
- 相邻按钮使用相同高度、内边距和箭头位置。
- 区块之间用留白和一条必要边界建立层次；不叠加短横线、卡片顶线、双重边界与重复下划线。

### 并排与叠加

两栏至少需要约 480px 文案、360px 图形与 40px 间隔，因此当前按**实际内容宽度 880px** 判断是否叠加。不能仅因窗口变高而切换构图。

叠加时延续等宽字体、标题字重和连续字号；图形重心对齐主标题中心，不能对齐包含副标题与按钮的整块容器。官网背景透明度约 15%，以不干扰文字为准。

## 6. 图形语言

主图使用规则生成的递归折线；四阶段图形对应经验、抽象、组合、新能力。应保留结构的可追踪性，而非制造随机噪声。

- 使用正交折线、清晰转折和克制的网格。
- 墨色表示已有结构，朱红表示当前推进位置或选中路径。
- 四阶段标题上方使用一条贯穿横线，阶段间采用 [工业阶梯箭头](assets/icons/loop-arrow-lattice.svg)，官网尺寸 36×24px。
- 图形与文字比较**实际可见重心**；透明画布的几何中心不能代替视觉校准。
- 需要边缘渐隐时，在原画面外扩展过渡带，保留原有完整显示范围与比例，避免通过向内遮罩变相缩小图形。

平面输出将递归图形冻结为清晰的一帧：保留完整路径与一个推进重点，避免截取闪烁、断裂或未完成到无法辨认的状态。

## 7. 动效与交互

动效表达持续推进。避免高速闪烁、频繁重启、明显倒放或无意义的弹跳。

- 首屏递归曲线继续生长，镜头变化保持平滑。
- 四阶段共用 24 秒归一化周期，阶段复杂度不同也不改变总体节奏。
- 悬停只突出邻近路径，位移约 3px，不突然加速动画。
- 减少动态效果模式应有稳定静态画面；触摸交互不阻断页面滚动。
- 保留键盘焦点与清晰的点击区域，信息不能只靠颜色或动画传达。

## 8. 中英文与文案

两种语言分别组织完整排版，保持同一主张，不追求逐字对照。

- 中文使用自然短句，减少宣传短句末尾重复句号；不堆叠抽象名词。
- 英文优先短句、主动动词与平行结构，例如 `Make Intelligence Compound`。
- `Recursive Self-Improvement` 是一个完整概念，可分行，但保持同一强调层级，不把 `Recursive` 附在另一层标题后面。
- 换行落在语义边界，不为了填满一行拆散概念；窄屏允许自然续行。
- 愿景与研究结果分别表达：可以明确追求递归自我改进，不能把尚在探索的目标写成已证实能力。
- 语言切换不应改变导航列宽或触发另一套设计风格。

## 9. 按钮、导航与页脚

主按钮使用墨黑底、冷白文字；次按钮使用透明底、清晰边框。首屏按钮桌面高度约 64px、手机约 60px，字号 18px；双入口等宽，避免一个按钮明显轻弱。

官网页眉使用黑底浅字，滚动时固定在顶部。首页产品入口采用紧凑文字链接，分别通往桌面端介绍、DSH 插件介绍和现有 Web 登录页。研究文章与招募页面文件保留，但不在主导航增加“研究／加入我们”。所有公开内容页面共用品牌、口号、导航与版权的页脚结构。

语言入口显示可切换的语言，单击切换；沿用顶栏字体和交互样式。

## 10. 延展与交付

海报、封面或演示材料建议采用“一句主张＋一组递归结构＋一个行动入口”的内容层级。中文主张正体加粗；辅助说明保持克制。先沿用颜色、字体、标识和网格，再按载体调整比例，不把网页断点机械套在纸张上。

交付前检查：

- 标识与字标的可见高度、重心是否一致。
- 标题、说明、图形是否存在明确对齐关系，字形下伸部是否碰到正文。
- 同级编号、标题、按钮的尺寸与间距是否一致。
- 窄屏和中英文切换是否出现截断、挤压、悬空或风格跳变。
- 图形是否过密，是否出现重复细线和多余边框。
- 字体授权是否随包保留，外链是否准确，是否混入其他风格或调试产物。
