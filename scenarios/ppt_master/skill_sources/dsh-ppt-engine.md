# dsh-ppt 执行模块的 GeneLoop 适配参考

参考上游MIT代码，固定commit见third_party/dsh-ppt/PROVENANCE.json。不是另一个Skill执行入口。

build_ppt把整份当前内容计划直接变成文字、表格、图片和可编辑图表；表格分页不丢末行。patch_ppt用稳定页面ID及整数expected_revision修改原工程，0有效，成功页与备注保留。二者都接回共同PPTX/PDF/PNG交付链，预览失败保留项目并用空patch恢复。不导入任意外部PPTX或Office手工变化，不增加旁白、演示视频、HTML放映、独立AI预审或模型调用。

旧SVG、已有PPTX路线保留，按表达能力预先选择一次，不先试用再重建。已由共同底座完成的生成、分页、导出阶段是工程能力，不计算成学得Motif或跳过模型请求。

学习搜索方向：观察正常任务中的来源字段到图表/表格参数绑定、反馈到页面字段的反复映射、明确失败后实际有效的修复。Skill只提示搜索位置；顺序、循环、参数、适用条件必须来自真实轨迹。旧页面SHA证书不授权新整数revision工具。只有新的独立执行认证及后继采用才能登记相应能力，留出任务不回灌。
